# M14 设计：用 myui 复刻 duanxianxia.com 首页

日期：2026-08-04　状态：已批准执行
参考依据：duanxianxia.com 首页 HTML/CSS 静态分析（无 headless 浏览器，视觉基准 = HTML 结构 + index.css 色值 + FetchURL 渲染文本快照，存 /tmp/dxx/）。

## 1. 目标与边界

用当前 myui 框架实现 duanxianxia.com（短线侠）**首页**的布局与交互，视觉逐项对齐（色值取自 index.css 实测：#444 顶栏、#e64c62 主红、#eaf1fe 筛选底、#347DFA 按钮蓝、red/green 涨跌色）；数据用抓取时刻的真实静态快照（晋级表 5 行 + 指数 12 项 + 直播面板模拟内容）。不做：后端动态数据、其余子页面（导航切换以占位内容表达交互形式）、微信/分享真实功能。

## 2. 页面结构（实测 HTML 推导）

1. **顶栏**（#444，50px）：logo（图片→以文字"短线侠"模拟）+ 下拉菜单 4 组（竞价▾：竞价异动/竞价强度；挖掘▾：个股挖掘/概念检索/研报检索；复盘▾：每日复盘/板块轮动/龙头高度/连板天梯；热点▾：热点聚焦/聚合热搜）+ 平铺项（语音快讯/看盘插件[orange]/涨停表现/龙虎榜/PC端版面[yellow bold]/联系客服），项间竖分隔线；右侧 注册/登录（白色 16px）。
2. **指数条**（白底阴影卡片，12 项等宽）：上证/深成/创业板/恒生/恒生科技/富时A50/上证50/沪深300/中证2000/道指期货/纳指期货/COMEX黄金——名称 + 数值 + 涨跌幅（红涨绿跌）。数值用合理静态快照（当日约值，注明数据为快照）。
3. **双列直播区**（间距 flex）：左 750px 情绪直播（时间+文本流列表）；右列 530px 四面板：涨停直播 400px / 异动 160px / 股票池 430px / 成交额 250px——标题栏 + 滚动列表，内容静态模拟。
4. **涨停股票池表格**：表头（进度 60px / 晋级率 85px / "涨停股票池" + 右侧红色"分享图片"按钮）；行 = 6进7、4进5、3进4、2进3（7/12=58%）、1进2（6/42=14%）、首板（62/72=86%）；股票项 = 市场徽标（沪/深/创/科/北着色小签）+ 名称 + 状态（成=红粗体 / 败=绿 / 炸=橙）+ [涨幅]（正红负绿）+ 题材标签（小字换行）。数据用 FetchURL 抓取的完整快照。
5. **页脚**：免责声明 + 粤ICP备2025400938号 | 395838961@qq.com。

## 3. 交互复刻

- 下拉菜单：点击展开（my_menu），项点击切换内容区占位面板（标题变化）。
- 注册/登录：my_dialog（用户名/密码 edit + 确认按钮——展示 edit/IME/MVVM 能力）。
- 分享图片：点击弹 dialog 提示（复刻形式）。
- 股票项：hover 高亮 + tooltip（详情：名称/状态/涨幅/题材）；点击弹个股卡片 dialog。
- 整页垂直滚动（内容 1300px+ 超过窗口）。

## 4. 框架补齐（M14a，TDD）

- `my_layouter_flow`：横向流式换行布局器（股票项流式排布必需；现有 linear 不支持换行）。
- `my_rich_label`：行内多段文本控件（段 = 文本+颜色+粗体标志；名称红/题材灰/涨幅红绿混排必需）。
- `my_scroll_view`：通用滚动容器（任意子树垂直滚动 + scroll_bar；list_view 不适配异构内容）。
- hover enter/leave 事件补全：分发器维护 hover 控件，widget 增 hover 视觉态驱动（style 的 hover 槽自动生效），emit "hover_enter"/"hover_leave"。
