# M20 设计：节点编辑器增强（磁吸/AA/缩放/框选/小地图/级联删除/流动画）

日期：2026-08-14　状态：已批准执行

## 1. 需求与方案

1. **连线磁吸**：连线预览态下，距候选接口 ≤20px（画布坐标）时预览端点吸附到接口圆心，候选接口画高亮环；离开范围解除。吸附计算按类型匹配（输出→只吸输入，反之亦然）。
2. **连线抗锯齿**：核查 node_view 绘制链路的 AA 级别——贝塞尔 stroke 走覆盖率 AA 路径，确保 node_view 显式开启 level 2（若 window 未传则 vg 默认开？核实并固化）；接口圆点（kappa 贝塞尔）同链路 AA；golden 目检。
3. **画布缩放**：node_view 增 zoom（0.25–2.0，滚轮 Ctrl+滚轮或以光标为锚缩放）；绘制经 vgcanvas set_scale（M12c 已有）+ pan/zoom 坐标换算；事件命中经逆变换（view 层把屏幕坐标转画布坐标再分发子控件）。滚轮默认=缩放（Blender 惯例），平移改拖空白/中键。
4. **框选多选**：空白处拖出选择框（虚线矩形+半透明填充），松手选中相交节点（多选）；选中节点可整体拖动；Del 删除全部选中节点（连带清线）；点击空白清空选择。
5. **小地图**：右下角 160x100 迷你画布（深色底+节点色块缩略+视口矩形框），随 pan/zoom 实时；点击小地图将视口中心移到对应位置。
6. **节点删除连带清线**：`my_node_view_remove_node`：断开并移除该节点全部连线 + changed 事件。
7. **连线流动画**：选中/全部连线做"行军蚁"虚线流动（dash 沿贝塞尔参数 t 周期推进，33ms tick 驱动 invalidate；默认开选中连线流动、普通连线静态，全部可 CSS 控制 `node_link.flow`？——简化为：全部连线流动可全局开关，默认关，选中流动默认开）。

## 2. 里程碑

- **M20a**：磁吸 + AA 核查/固化 + 缩放（含坐标换算全套）+ 级联删除。
- **M20b**：框选多选（含多选拖动/删除）+ 小地图 + 连线流动画 + demo 更新 + 文档 + 推送。
